# M4 - In-game runtime map editor (MVP)

## Goal

Make the map-editor functionality usable **inside the running game**, not just in
the Godot editor. A player/developer opens "Map editor" from the main menu,
authors a map with the same three tools as the plugin (lanes, buildings, tiles),
saves it under `user://maps/`, validates it, and boots it for a test match.

This is a **separate runtime editor scene**, not an overlay on a live match.
That avoids fighting the GOAP pump, spawn timers, unit registration and the
game camera while editing.

## Fixed decisions (do not re-litigate)

1. **Editor APIs cannot run at runtime.** `EditorPlugin`, `EditorInterface`,
   `get_undo_redo()`, `_forward_canvas_gui_input`, `_handles`,
   `add_control_to_dock` and `EditorDock` are editor-only. Runtime code must
   not reference them.
2. **Reuse the editor-free logic in place.** `lane_logic.gd`,
   `building_logic.gd`, `tile_brush_logic.gd`, `map_scaffold.gd` and
   `map_validator.gd` are `RefCounted` and already headless-tested. Runtime may
   preload them from `res://addons/map_editor/`. Do not edit
   `map_editor_plugin.gd` or `editor_dock.gd` in M4.
3. **Runtime undo uses `UndoRedo.new()`**, not `EditorPlugin.get_undo_redo()`.
4. **Maps live under `user://maps/`.** `res://` is read-only in exported
   builds. Do not add a res:// save path.
5. **Players are blue, enemies red** for Play-test, matching `main_menu.gd`'s
   quick-start defaults.
6. **Editor-only visibility changes must never be saved.** The editor hides
   fog and unit HUDs for usability; those `visible` flags must be restored
   before `PackedScene.pack()` and hidden again afterwards.
7. **One branch / one focused change.** Suggested branch:
   `feature/runtime-map-editor`.

Verified facts from headless probes (already true in this checkout):

- A runtime-built/edited map can be `PackedScene.pack()`ed and
  `ResourceSaver.save()`d to `user://`, reloaded, and validated with 0 errors.
- Calling the scaffold's owner-assignment pattern before saving preserves
  instanced-building internals: an instanced church keeps its `hud` owned by
  the church, while the church is owned by the map.
- At runtime, camera pan/zoom lives in
  `get_viewport().get_canvas_transform()`, and
  `CanvasItem.get_global_transform_with_canvas()` includes it.
  **`get_global_canvas_transform()` is identity at runtime** — that is the
  editor-only transform from M1. Do not use it here.

## Step 1 — `map/editor/map_store.gd` (new, pure RefCounted)

This is the only file that writes/reads map files. Keep it editor-free and
headless-testable.

Required API:

```gdscript
extends RefCounted

const MAP_DIR := "user://maps"
const MAP_EXT := ".tscn"

static func ensure_dir() -> void            # make_dir_recursive_absolute(MAP_DIR)
static func sanitize_name(raw: String) -> String
static func path_for(name: String) -> String # MAP_DIR + "/" + sanitize_name(name) + MAP_EXT
static func list_maps() -> PackedStringArray # basenames of *.tscn, sorted
static func save_map(map_root: Node, name: String) -> int
static func load_map(name: String) -> Node   # null on failure
static func delete_map(name: String) -> int
static func own_tree(node: Node, owner: Node) -> void
```

Implementation requirements:

- `sanitize_name` must prevent path traversal and invalid file names:
  strip `..`, `/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`, replace spaces
  with `_`, trim whitespace and leading/trailing dots, and return `"map"` when
  the result is empty. Never let a caller write outside `user://maps/`.
- `save_map`:
  ```gdscript
  ensure_dir()
  own_tree(map_root, map_root)
  var packed := PackedScene.new()
  var err := packed.pack(map_root)
  if err != OK:
      return err
  return ResourceSaver.save(packed, path_for(name))
  ```
  `own_tree` must be the same shape as `map_scaffold.gd`'s `_assign_owner`:
  recurse into children only while `child.get_owner() == null`, set
  `child.owner = owner`, recurse. This keeps instanced-building internals
  serialized as instances and prevents their internal nodes being flattened
  into the map scene.
- `load_map`:
  ```gdscript
  var path := path_for(name)
  if not FileAccess.file_exists(path):
      return null
  var res = load(path)
  if not (res is PackedScene):
      return null
  var map: Node = (res as PackedScene).instantiate()
  own_tree(map, map)
  return map
  ```
- `list_maps` must return `[]` when `user://maps` does not exist and must not
  include directories or non-`.tscn` files.
- `delete_map` may delete only files under `MAP_DIR` produced by `path_for`.

## Step 2 — `map/map_manager.gd`: resolve runtime map paths

Change `_resolve_map_scene()` so it accepts a direct path and a user-map name.
Keep the existing preloaded fast path for shipping maps.

```gdscript
func _resolve_map_scene(map_name: String) -> PackedScene:
	if map_name.begins_with("user://") or map_name.begins_with("res://"):
		return load(map_name) as PackedScene
	var preloaded = get(map_name)
	if preloaded is PackedScene:
		return preloaded
	var res_path := "res://map/maps/%s.tscn" % map_name
	if ResourceLoader.exists(res_path):
		return load(res_path)
	var user_path := "user://maps/%s.tscn" % map_name
	if FileAccess.file_exists(user_path):
		return load(user_path)
	return null
```

Rules:

- Check the path prefixes **before** `get(map_name)`; a slashed string is not a
  property name.
- Do not change `load_map()`'s container/WorldState behavior.
- The existing `tests/unit/test_map_loader.gd` assertions must keep passing.

## Step 3 — Runtime editor scene and camera

Create `map/editor/map_editor.tscn` with this tree:

```text
MapEditor (Node2D, script map_editor.gd)
├── EditorCamera (Camera2D, script editor_camera.gd)
├── MapHolder (Node2D)                 # edited map is added here
├── LaneOverlay (Node2D, script lane_overlay.gd)
└── UILayer (CanvasLayer)
    └── EditorUI (Control, script editor_ui.gd, full rect)
```

`MapHolder` and `LaneOverlay` are siblings so the overlay draws above the map.
The overlay is **not** a child of the map root, so it is never saved.

### `editor_camera.gd`

`extends Camera2D`. Required methods:

```gdscript
func frame_map(size: Vector2, viewport_size: Vector2) -> void
func handle_input(event: InputEvent) -> bool
```

- `frame_map`: `position = size / 2.0`; zoom so the map fits the viewport:
  `var z = minf(viewport_size.x / maxf(size.x, 1.0), viewport_size.y / maxf(size.y, 1.0))`;
  clamp z to `0.25 .. 4.0`; set `zoom = Vector2(z, z)`.
- `handle_input`:
  - middle mouse button press/release starts/stops panning (`MOUSE_BUTTON_MIDDLE`);
  - mouse motion while panning moves `position -= event.relative / zoom`;
  - mouse wheel up/down zooms in/out around the camera center, clamped to
    `0.25 .. 4.0`;
  - return `true` when the event was consumed.
  - If a motion event arrives while panning but `event.button_mask` no longer
    has the middle button, stop panning (the release may have been consumed by
    the UI).
- Call `make_current()` in `_ready()` so the autoloaded `CraftyCamera` cannot
  steal the view.
- Do not use `CraftyCamera` for editing; it is tied to `game_started` and
  gameplay.

### `lane_overlay.gd`

`extends Node2D`.

```gdscript
var lane: Line2D
func _draw() -> void:
	if lane == null or not is_instance_valid(lane):
		return
	var pts := PackedVector2Array()
	for i in lane.get_point_count():
		pts.append(to_local(lane.to_global(lane.get_point_position(i))))
	if pts.size() >= 2:
		draw_polyline(pts, Color(0.3, 0.7, 1.0, 0.9), 2.0, true)
	for p in pts:
		draw_circle(p, 4.0, Color(0.3, 0.7, 1.0, 1.0))
```

Call `queue_redraw()` whenever the selected lane or its points change.

### `map_editor.gd`

`extends Node2D`. State:

```gdscript
@onready var camera := $EditorCamera
@onready var map_holder := $MapHolder
@onready var lane_overlay := $LaneOverlay
@onready var ui := $UILayer/EditorUI

var map_root: Node2D = null
var undo_redo := UndoRedo.new()
var mode := ""              # "", "lane", "building", "tile"
var _stroke: Dictionary = {} # {"layer": TileMapLayer, "erase": bool, "undo": {}}
```

`_ready()`:

- connect UI signals;
- `camera.make_current()`;
- `ui.set_map_root(null)`; log `"New map or Open a saved map."`;
- do **not** auto-create a map.

`_install_map(map: Node2D, display_name := "untitled")`:

1. `_commit_stroke()` and set mode off (sync UI toggles).
2. If an old map exists: `map_holder.remove_child(old); old.queue_free()`.
3. `map_holder.add_child(map)`; `map_root = map`.
4. `MapStore.own_tree(map, map)` — required before painting because
   `TileBrush.mirror_size_for()` reads `layer.get_owner() as BaseMap`, and
   before saving for owner preservation.
5. Hide editor-unfriendly visuals via `_hide_for_editing(map)` (below):
   fog, `zoom_out_sprite`, and every building `hud` child. Do **not** hide
   `lanes`; leave its authored visibility alone.
6. `undo_redo.clear_history()`.
7. `lane_overlay.lane = null`; `ui.set_map_root(map)`;
   `ui.set_map_name(display_name)`; `ui.refresh_lanes()`;
   `ui.refresh_map_list()`; `camera.frame_map(map.size, get_viewport_rect().size)`.
8. Log `"Editing <name>"` and `queue_redraw()`.

Editor-only visibility helpers (required, because stale hidden flags would be
serialized into the .tscn):

```gdscript
var _editor_hidden: Array = []   # [{"node": Node, "visible": bool}]

func _hide_node(node: Node) -> void:
	if node == null:
		return
	_editor_hidden.append({"node": node, "visible": node.visible})
	node.hide()

func _hide_for_editing(map: Node) -> void:
	_editor_hidden.clear()
	_hide_node(map.get_node_or_null("fog"))
	_hide_node(map.get_node_or_null("zoom_out_sprite"))
	var buildings := map.get_node_or_null("buildings")
	if buildings == null:
		return
	for team in buildings.get_children():
		for building in team.get_children():
			_hide_node(building.get_node_or_null("hud"))

func _restore_for_save() -> void:
	for entry in _editor_hidden:
		var node: Node = entry["node"]
		if is_instance_valid(node):
			node.visible = entry["visible"]
	_editor_hidden.clear()

func _hide_again_after_save() -> void:
	_hide_for_editing(map_root)
```

Call `_hide_for_editing(map)` in `_install_map`. A newly placed building's HUD
must also be hidden through `_hide_node(building.get_node_or_null("hud"))`
after it is added. Saving must always do:

```gdscript
_restore_for_save()
var err := MapStore.save_map(map_root, ui.map_name())
_hide_again_after_save()
```

This is the only reason the save path touches visibility. Do not hide lanes or
the map root.

`New map`: `_install_map(Scaffold.new().build_map(), "untitled")`.

`Open map`: `var map = MapStore.load_map(name); if map: _install_map(map, name)`.

`Save map`:

1. `_commit_stroke()`.
2. `_restore_for_save()`; `var err = MapStore.save_map(map_root, ui.map_name())`;
   `_hide_again_after_save()`.
3. Run `Validator.new().validate(map_root)`; log every problem.
4. Log the absolute path on success; do not block saving on validation errors
   (never lose the user's work). Play-test is the step that blocks errors.
5. `ui.refresh_map_list()`; `ui.set_map_name(MapStore.sanitize_name(ui.map_name()))`
   so the field matches the file that was written.

`Validate`: `_commit_stroke()` first, then run the validator on `map_root`,
logging errors then warnings.

`Delete map`: `MapStore.delete_map(name)`, refresh the list, log.

`Exit`: `get_tree().change_scene_to_file("res://game.tscn")`.

`Play`:

1. `_commit_stroke()`.
2. Run validator; if any `level == "error"`, log and refuse.
3. Save through the same visibility-safe path as Save:
   `_restore_for_save()`; `MapStore.save_map(map_root, ui.map_name())`;
   `_hide_again_after_save()`; abort on error.
4. `WorldState.set_state("pending_map", MapStore.path_for(ui.map_name()))`.
5. `get_tree().change_scene_to_file("res://game.tscn")`.

## Step 4 — Input and the three tools (`map_editor.gd`)

Use `_unhandled_input(event)` so a click on the UI is consumed by the UI first.

```gdscript
func _unhandled_input(event: InputEvent) -> void:
	if camera.handle_input(event):
		get_viewport().set_input_as_handled()
		return
	if event is InputEventKey and event.pressed and not event.echo:
		if event.keycode == KEY_ESCAPE and mode != "":
			_set_mode("")
			get_viewport().set_input_as_handled()
			return
		if event.ctrl_pressed and event.keycode == KEY_Z:
			undo()
			get_viewport().set_input_as_handled()
			return
		if event.ctrl_pressed and event.keycode == KEY_Y:
			redo()
			get_viewport().set_input_as_handled()
			return
	if mode == "" or map_root == null:
		return
	# then dispatch lane/building/tile mouse handling; call
	# get_viewport().set_input_as_handled() for every consumed event
```

`undo()` and `redo()` must call `_commit_stroke()` first, then
`undo_redo.undo()`/`undo_redo.redo()`, then `_refresh_after_change()`
(overlay redraw, lane list refresh, tile picker refresh if needed).
`_set_mode("")` must also commit the active stroke and sync both mode toggles.
Entering lane mode must call `_sync_overlay(ui.selected_lane_name())` so the
overlay follows the dropdown without requiring a click first.

For tile motion, only continue a stroke while the relevant button is still
held: `event.button_mask & MOUSE_BUTTON_MASK_LEFT` for paint and
`MOUSE_BUTTON_MASK_RIGHT` for erase. If the release was consumed by the UI,
stop the stroke instead of painting on later motion.

### Runtime coordinate rule

Every click arrives in **viewport** coordinates. Convert with the runtime canvas
transform, **not** the editor one:

```gdscript
var canvas := get_viewport().get_canvas_transform()

# Lane (points are lane-local)
var xform := LaneLogic.viewport_to_node_xform(lane, canvas)
var local := LaneLogic.snap_point(xform.affine_inverse() * event.position)

# Building (position is team-node-local)
var local := LaneLogic.snap_point(
	LaneLogic.viewport_to_node_xform(team_node, canvas).affine_inverse() * event.position)

# Tiles
var local := TileBrush.viewport_to_local(layer, event.position, canvas)
```

Never use `get_global_canvas_transform()` here — it is identity at runtime.
Do not copy M1's editor-only conversion; at runtime
`get_viewport().get_canvas_transform()` is the correct camera transform, and
`CanvasItem.get_global_transform_with_canvas()` includes it.

### Lane tool

- Selected lane: `ui.selected_lane_name()`; resolve
  `map_root.get_node_or_null("lanes/" + name)`. If none, log and return.
- Connect UI `lane_selected(name)` to `_sync_overlay(name)`, which sets
  `lane_overlay.lane` to that lane and calls `queue_redraw()`. Call the same
  helper after `refresh_lanes()` and after creating a lane.
- Left press: compute local snapped point, `index = LaneLogic.insertion_index(lane, local)`,
  then one `undo_redo` action:
  - do: `lane.add_point(local, index)`
  - undo: `lane.remove_point(index)`
  - commit.
- `lane_overlay.queue_redraw()` after the point is added.
- `New lane`: create `Line2D.new()`, name = `LaneLogic.next_lane_name(lanes)`,
  `default_color = Color(1,1,1,0.196078)`, then one undo action:
  do `lanes.add_child(lane)` + `lane.set_owner(map_root)`, undo
  `remove_child(lane)` + `queue_free()`; refresh UI lanes, call
  `ui.select_lane(lane.name)`, and `_sync_overlay(lane.name)`.

### Building tool

- Palette: `ui.selected_building_scene()`.
- Team: `ui.selected_team()` (`blue`/`red`/`neutral`).
- Neutral host: `BuildingLogic.neutral_host_team(map_root)`; refuse when empty.
- `base_name = BuildingLogic.building_base_name(scene_path)`;
  refuse if `not BuildingLogic.is_placement_allowed(base_name, team)`.
- Resolve `team_node = BuildingLogic.place_target(map_root, parent_team)`.
  Refuse when null.
- Require a selected lane; subtype is `lane.name`.
- Instantiate, set `name = BuildingLogic.next_building_name(team_node, base_name)`,
  `position = local`,
  `BuildingLogic.apply_building_meta(building, base_name, team, lane.name)`, and
  `BuildingLogic.apply_editor_team_visuals(building, building.team)`.
- One undo action: do `team_node.add_child(building)` + `building.set_owner(map_root)`;
  undo `remove_child(building)` + `queue_free()`.
- Important: metadata must be set **before** `add_child` (the Node API
  auto-dedupes sibling names otherwise), and `apply_building_meta` must receive
  the **kind** (`base_name`), never the minted name (`tower_2`). The `team`
  argument is the metadata team (`neutral` for neutrals), while the parent
  directory is `parent_team` from `neutral_host_team()`.
- After adding, hide the new building's HUD through `_hide_node()` so editor
  preview and save-time restore stay consistent.
- Log scene, snapped position, team, resolved name, subtype.

### Tile tool

Copy the plugin's shape, but use the runtime `undo_redo` and UI getters:

- `brush = ui.selected_brush()`; `layer = TileBrush.layer_for_brush(map_root, brush)`.
- `cell_size = TileBrush.cell_size_of(layer)`; if ZERO log and return.
- On stroke start: use the host's runtime `undo_redo` —
  `undo_redo.create_action("Erase tiles" if erase else "Paint tiles")`;
  `_stroke = {"layer": layer, "erase": erase, "undo": {}}`.
- For walls, call `TileBrush.walls_guard_message(map_root, brush, layer)` before
  painting; log and return on a non-empty guard.
- Cells:
  - if `ui.selected_block_is_full_tile()`:
    `TileBrush.paint_cells_for_local(layer, local, int(map_root.tile_size))`
  - else:
    `TileBrush.block_cells(TileBrush.viewport_to_cell(layer, event.position, canvas), ui.selected_block_cells())`
- Tile selection: `var tile = {} if erase else ui.selected_tile()`;
  if not erase and tile.is_empty(): log `"No tile selected."` and return;
  `source_id = -1 if erase else int(tile.get("source_id", -1))`;
  `atlas = Vector2i(-1,-1) if erase else tile.get("atlas_coords", Vector2i(-1,-1))`.
- For each cell, call `_paint_cell_in_stroke()` (same logic as
  `map_editor_plugin.gd:395-415`): record pre-state **once per cell per stroke**,
  queue do/undo methods using real `TileMapLayer` methods (`set_cell`,
  `erase_cell`), and apply immediately.
- Mirror: `var mirrored = TileBrush.mirrored_cell(coords, cell_size, TileBrush.mirror_size_for(layer))`;
  write the mirror cell too when different.
- Left button paints; right button erases; motion while `_stroke` is not empty
  paints/erases; button release calls `_commit_stroke()`.
- `_commit_stroke()` commits and clears `_stroke`; call it on release, Escape,
  mode switch, save, and exit. It must be safe when `_stroke` is empty.
- Do not use `restore_cell_state` as an undo Callable — it is a static helper on
  a different object and is invalid as a Callable (the M3 bug).

## Step 5 — Runtime UI (`editor_ui.gd`)

`extends Control`. Build the UI in `_ready()` like `editor_dock.gd` does, but
with **no EditorInterface calls** and no FileDialog.

Signals emitted to the host:

```gdscript
signal new_map_requested
signal open_map_requested(map_name: String)
signal save_map_requested
signal delete_map_requested(map_name: String)
signal validate_requested
signal play_requested
signal exit_requested
signal lane_mode_requested(active: bool)
signal building_mode_requested(active: bool)
signal tile_mode_requested(active: bool)
signal new_lane_requested
signal lane_selected(lane_name: String)
signal undo_requested
signal redo_requested
```

Set `EditorUI.mouse_filter = Control.MOUSE_FILTER_IGNORE` so the full-rect root
does not eat map clicks; the left `PanelContainer` (and the `ScrollContainer`
inside it) must use `MOUSE_FILTER_STOP`. Wrap the dock controls in a
`ScrollContainer` — there are more controls than fit a 600px-tall window.

Controls, in a left-side `PanelContainer` (set `mouse_filter = STOP` so clicks do
not fall through to the map):

- Buttons: `New map`, `Save`, `Delete`, `Validate`, `Play`, `Exit`.
- Map list: `OptionButton` populated by `MapStore.list_maps()`; an `Open`
  button emits the selected name. A `Refresh` button repopulates it.
- Name: `LineEdit` with default `"untitled"`.
- Lane: a lane `OptionButton`, `New lane` button, and `Draw lanes` toggle.
  The lane dropdown emits `lane_selected(name)` on `item_selected`.
- Buildings: `Place buildings` toggle, building-scene `OptionButton`
  (`BuildingLogic.list_building_scenes()`), team `OptionButton`
  (`BuildingLogic.TEAM_DIRECTORIES` + `"neutral"`).
- Tiles: `Paint tiles` toggle, brush `OptionButton` (`TileBrush.BRUSHES.keys()`),
  tile `OptionButton`, block `OptionButton` (from
  `TileBrush.block_options_for(TileBrush.cell_size_of(layer), map_tile)`).
  Tile entries may be text (`"s%d %s"`) — icons are optional for the MVP.
- `Undo` / `Redo` buttons.
- `RichTextLabel` log; append every action and validator result.

Methods the host calls:


`refresh_tile_picker()` must resolve the layer via
`TileBrush.layer_for_brush(map_root, selected_brush())`; when there is no map or

current selection when possible and select a newly created lane.

Windowed run, not headless:

```bash
.tools/godot/Godot_v4.7.2-stable_linux.x86_64 --path .
```

1. Main menu → **Map editor**.
2. **New map**; the scaffold appears; fog/HUD labels are hidden.

   land under the cursor on the 64px grid and the blue overlay tracks them
   while panning (middle-drag) and zooming (wheel).

5. **New lane**; draw two points; the new lane is selected and listed.
6. **Place buildings**: pick `church`, team `blue`, click; it appears under
   `buildings/blue`, has `team = "blue"`, and undo removes it.
7. **Paint tiles**: ground/walls/trees brushes; left paints, right erases, drag
   paints; walls guard logs if the TileSet cell size is wrong.
8. **Undo/Redo** step through the lane point, building and tile stroke.
9. **Save**; check the log for the user:// path and validation results.
10. **Open** the saved map; edits survive; re-open after restarting the editor.
11. **Validate**; scaffold has 0 errors.
12. **Play**; the game boots on the saved map as blue vs red; return to the
    main menu via the game's normal flow.
