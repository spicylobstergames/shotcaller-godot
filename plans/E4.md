# E4 - Make WorldState timer setup idempotent

`setup_timers()` creates and adds a new Timer per call and never stops the old
one; `clear_state()` leaves timers running. Reuse the timer or stop/free it
first.

Detail and evidence: `../IMPROVEMENT_PLAN.md` (Track E).
